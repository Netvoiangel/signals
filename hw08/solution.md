# ДЗ 8 — порядки элементов в \(GF(5^2)\) и \((15,4)\)-код

## Задача 1

Для мультипликативной группы поля \(GF(5^2)\), считая \(x\) примитивным элементом, определить порядки всех элементов поля.

---

### 1) Порядок мультипликативной группы

Рассматриваем поле

\[
GF(5^2)=GF(25).
\]

В поле 25 элементов, а мультипликативная группа состоит из всех ненулевых:

\[
GF(25)^*=GF(25)\setminus\{0\},
\]

поэтому

\[
|GF(25)^*|=25-1=24.
\]

По условию \(x\) — примитивный элемент, значит он порождает всю группу:

\[
GF(25)^*=\{1,x,x^2,\dots,x^{23}\},\qquad x^{24}=1.
\]

Для элемента \(x^k\) порядок:

\[
\operatorname{ord}(x^k)=\frac{24}{\gcd(24,k)}.
\]

Для \(k=0\): \(x^0=1\), поэтому \(\operatorname{ord}(1)=1\).  
Нулевой элемент \(0\) не входит в мультипликативную группу, следовательно мультипликативного порядка не имеет.

## Задача 2

Для кодера \((15,4)\)-кода с проверочным полиномом

\[
h(x)=1+x+x^4
\]

описать смену состояний регистра при начальном заполнении \(0,0,1,1\), убедиться, что код максимальной длины, и определить минимальное расстояние.

---

### 1) Параметры и рекуррентное соотношение

\[
\deg h(x)=4 \Rightarrow k=4,\quad n=15.
\]

То есть это \((15,4)\)-код.

Из

\[
h(x)=1+x+x^4
\]

получаем рекуррентную связь:

\[
a_i+a_{i+1}+a_{i+4}=0,
\]

а над \(\mathbb F_2\):

\[
a_{i+4}=a_i+a_{i+1}\pmod 2.
\]

Начальное состояние:

\[
a_0a_1a_2a_3=0011.
\]

---

### 2) Смена состояний регистра

Используем правило \(a_{i+4}=a_i+a_{i+1}\):

\[
0011 \to 0110 \to 1101 \to 1010 \to 0101 \to 1011 \to 0111 \to 1111
\]
\[
\to 1110 \to 1100 \to 1000 \to 0001 \to 0010 \to 0100 \to 1001 \to 0011.
\]

До возврата к начальному состоянию получаем 15 различных ненулевых состояний.

---

### 3) Проверка максимальной длины

Для регистра длины 4 всего состояний:

\[
2^4=16.
\]

Нулевое состояние \(0000\) не входит в ненулевой цикл, значит максимальная длина ненулевого цикла:

\[
2^4-1=15.
\]

Мы получили ровно 15 состояний до возврата, следовательно период максимален и это код максимальной длины.

---

### 4) Минимальное расстояние

Код максимальной длины с параметрами \((2^m-1,m)\) является симплекс-кодом (дуальным к коду Хэмминга), поэтому

\[
[n,k,d_{\min}]=[2^m-1,\ m,\ 2^{m-1}].
\]

При \(m=4\):

\[
[15,4,8].
\]

Следовательно,

\[
\boxed{d_{\min}=8}.
\]

---

## Проверка программой

```python
from math import gcd


# =========================
# Задача 1
# =========================
group_order = 5**2 - 1

print("Задача 1")
print("Порядок мультипликативной группы GF(5^2)*:", group_order)
print()

orders = {}
for k in range(group_order):
    if k == 0:
        order = 1
    else:
        order = group_order // gcd(group_order, k)
    orders[k] = order

print("Порядки элементов x^k:")
for k, order in orders.items():
    if k == 0:
        print(f"x^{k} = 1: порядок {order}")
    else:
        print(f"x^{k}: порядок {order}")

print()
print("Группировка по порядкам:")
by_order = {}
for k, order in orders.items():
    by_order.setdefault(order, []).append(k)

for order in sorted(by_order):
    elements = []
    for k in by_order[order]:
        if k == 0:
            elements.append("1")
        elif k == 1:
            elements.append("x")
        else:
            elements.append(f"x^{k}")
    print(f"Порядок {order}: {', '.join(elements)}")


# =========================
# Задача 2
# =========================
print()
print("Задача 2")

state = [0, 0, 1, 1]
seen = [tuple(state)]

print("Смена состояний регистра:")
for _ in range(15):
    print("".join(map(str, state)))
    # h(x) = 1 + x + x^4 => a_{i+4} = a_i + a_{i+1} (mod 2)
    new_bit = state[0] ^ state[1]
    state = [state[1], state[2], state[3], new_bit]
    seen.append(tuple(state))

print("".join(map(str, state)))

unique_nonzero_states = set(seen[:-1])

print()
print("Количество различных ненулевых состояний:", len(unique_nonzero_states))
print("Вернулись к начальному состоянию:", seen[0] == seen[-1])
print("Нулевое состояние встречается:", (0, 0, 0, 0) in unique_nonzero_states)

assert len(unique_nonzero_states) == 15
assert seen[0] == seen[-1]
assert (0, 0, 0, 0) not in unique_nonzero_states

print()
print("Регистр имеет максимальный период 2^4 - 1 = 15.")
print("Код является кодом максимальной длины.")
print("Параметры кода: [15, 4, 8].")
print("Минимальное расстояние d_min = 8.")
```
