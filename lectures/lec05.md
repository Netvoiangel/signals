# Конспект лекции 5

## Минимальная решетка линейного кода

## 1. Решетчатая диаграмма линейного кода

**Решетчатая диаграмма** (треллис) линейного кода — это ориентированный граф, развернутый по времени и описывающий все кодовые слова кода.

Идея треллиса: кодовое слово строится постепенно, символ за символом.

В треллисе:

- каждый ярус соответствует моменту времени;
- узлы яруса соответствуют состояниям;
- переходы между ярусами соответствуют символам кодового слова;
- каждый полный путь от начального состояния к конечному задает одно кодовое слово.

То есть треллис можно рассматривать как граф путей, представляющих все возможные кодовые слова.

---

## 2. Минимальная решетка

Решетка называется **минимальной**, если на каждом ярусе число состояний минимально возможное.

Смысл минимальности: если два пути имеют одинаковое прошлое или одинаковое будущее, их не нужно искусственно разделять на разные состояния.

Иначе говоря, в минимальной решетке нет лишних эквивалентных состояний.

Для линейного кода минимальная решетка единственна с точностью до изоморфизма: изображения могут отличаться, но структура остается той же.

---

## 3. Построение решетки по порождающей матрице

Пусть задан двоичный линейный код \(C\) с параметрами \((n,k)\), а его порождающая матрица \(G\) имеет размер \(k \times n\).

Каждое кодовое слово вычисляется по формуле

\[
c = uG, \qquad u \in \mathbb{F}_2^k,
\]

где \(u\) — информационный вектор. Все операции выполняются по модулю 2.

---

## 4. Минимальная спэновая форма

Чтобы построить минимальную решетку, удобно привести строки матрицы \(G\) к **минимальной спэновой форме**.

Для каждой строки \(g_i\) вводятся:

- \(b_i\) — индекс первого ненулевого элемента;
- \(e_i\) — индекс последнего ненулевого элемента.

Интервал \([b_i, e_i]\) называется **спэном строки**.

Он показывает, на каком участке кодового слова данная строка влияет на формирование символов.

Пример: если строка имеет ненулевые элементы в позициях 1, 3, 4, 6, то

\[
b_i = 1,\qquad e_i = 6,
\]

а ее спэн равен \([1,6]\).

---

## 5. Активные строки и состояния

Решетка строится по ярусам

\[
j=0,1,\dots,n.
\]

Строка считается активной на ярусе \(j\), если ее спэн уже начался, но еще не закончился:

\[
b_i \le j < e_i.
\]

То есть строка активна тогда, когда она еще может влиять на будущие символы кодового слова.

Состояние на ярусе \(j\) определяется линейной оболочкой активных строк:

\[
S_j = \langle g_i : b_i \le j < e_i \rangle.
\]

Если активных строк нет, то

\[
S_j = \{0\}.
\]

Начальное состояние (\(j=0\)) и конечное (\(j=n\)) — нулевые.

---

## 6. Переходы между состояниями

Переход из состояния \(S_j\) в \(S_{j+1}\) соответствует выбору очередного информационного символа.

На каждом шаге решается, включать ли в текущую сумму строку, которая начинает действовать на данном ярусе.

Одновременно формируется очередной символ кодового слова.

Следовательно, треллис описывает не только возможные состояния, но и процесс пошагового построения кодовых слов.

---

## 7. Пример построения решетки

Рассмотрим порождающую матрицу

\[
G=
\begin{pmatrix}
1&0&1&1&0&1\\
1&0&1&0&1&0\\
1&1&0&1&0&0
\end{pmatrix}.
\]

Здесь

\[
k=3,\qquad n=6.
\]

Скорость кода:

\[
R=\frac{k}{n}=\frac{3}{6}=\frac{1}{2}.
\]

---

## 8. Все кодовые слова

Так как \(k=3\), существует

\[
2^3=8
\]

информационных векторов.

Для каждого \(u=(u_1,u_2,u_3)\) кодовое слово вычисляется по формуле

\[
c=uG.
\]

Получаем таблицу:

| \(u_1\) | \(u_2\) | \(u_3\) | Кодовое слово |
|-------:|-------:|-------:|---------------|
| 0 | 0 | 0 | 000000 |
| 0 | 0 | 1 | 000111 |
| 0 | 1 | 0 | 011110 |
| 0 | 1 | 1 | 011001 |
| 1 | 0 | 0 | 110100 |
| 1 | 0 | 1 | 110011 |
| 1 | 1 | 0 | 101010 |
| 1 | 1 | 1 | 101101 |

Минимальный ненулевой вес равен 3, поэтому

\[
d_{\min}=3.
\]

---

## 9. Спэны строк матрицы

Выпишем спэны строк матрицы \(G\).

Первая строка:

\[
g_1=(1,0,1,1,0,1).
\]

Ненулевые элементы в позициях \(1,3,4,6\), значит

\[
b_1=1,\qquad e_1=6,\qquad [b_1,e_1]=[1,6].
\]

Вторая строка:

\[
g_2=(1,0,1,0,1,0).
\]

Ненулевые элементы в позициях \(1,3,5\), значит

\[
b_2=1,\qquad e_2=5,\qquad [b_2,e_2]=[1,5].
\]

Третья строка:

\[
g_3=(1,1,0,1,0,0).
\]

Ненулевые элементы в позициях \(1,2,4\), значит

\[
b_3=1,\qquad e_3=4,\qquad [b_3,e_3]=[1,4].
\]

---

## 10. Упорядочивание строк

Все строки начинаются с первого столбца, поэтому удобно упорядочить их по возрастанию правого конца спэна:

\[
g_3,\quad g_2,\quad g_1,
\]

так как

\[
e_3=4,\qquad e_2=5,\qquad e_1=6.
\]

Такое упорядочивание удобно: строки постепенно перестают быть активными.

---

## 11. Состояния на ярусах

Рассматриваем ярусы

\[
j=0,1,2,3,4,5,6.
\]

### Ярус \(j=0\)

Активных строк нет:

\[
S_0=\{0\}.
\]

Число состояний: \(1\).

### Ярус \(j=1\)

Активны \(g_3,g_2,g_1\), поэтому

\[
S_1=\langle g_3,g_2,g_1\rangle,
\]

число состояний: \(2^3=8\).

### Ярус \(j=2\)

Активны те же три строки:

\[
S_2=\langle g_3,g_2,g_1\rangle,
\]

число состояний: \(8\).

### Ярус \(j=3\)

Активны те же три строки:

\[
S_3=\langle g_3,g_2,g_1\rangle,
\]

число состояний: \(8\).

### Ярус \(j=4\)

Строка \(g_3\) завершила спэн, остаются \(g_2,g_1\):

\[
S_4=\langle g_2,g_1\rangle,
\]

число состояний: \(2^2=4\).

### Ярус \(j=5\)

Строка \(g_2\) завершила спэн, остается \(g_1\):

\[
S_5=\langle g_1\rangle,
\]

число состояний: \(2^1=2\).

### Ярус \(j=6\)

Все строки завершились:

\[
S_6=\{0\}.
\]

Число состояний: \(1\).

---

## 12. Профиль решетки

Профиль решетки — последовательность чисел состояний по ярусам.

Для примера:

\[
1,\ 8,\ 8,\ 8,\ 4,\ 2,\ 1.
\]

Сначала решетка расширяется (активны три строки), затем сжимается к нулевому состоянию по мере завершения спэнов.

---

## 13. Смысл переходов в решетке

Переходы между состояниями определяются информационными битами.

На каждом шаге к текущей сумме строк активная строка либо добавляется, либо нет.

Например, при переходе из \(S_0\) в \(S_1\) выбирается вектор

\[
u=(u_1,u_2,u_3).
\]

Если строки записаны в порядке

\[
g_3,\quad g_2,\quad g_1,
\]

то состояние первого яруса можно представлять как \((u_3,u_2,u_1)\).

Каждый переход одновременно формирует очередной символ кодового слова через соответствующий столбец матрицы \(G\) и выбранные коэффициенты строк.

Именно поэтому треллис удобен: он показывает и множество кодовых слов, и сам процесс их построения.

---

## 14. Теорема о минимальности

**Теорема.**  
Если порождающая матрица линейного \((n,k)\)-кода приведена к минимальной спэновой форме, то решетка, построенная по правилу активных строк, является минимальной.

### Идея доказательства

На ярусе \(j\) состояние задается линейной комбинацией активных строк.

Если два состояния различны, то существует активная строка, у которой коэффициенты в этих состояниях различаются.

Но активная строка влияет на будущие символы (ее спэн еще не завершен), значит возможные продолжения путей из этих двух состояний различны.

Следовательно, такие состояния нельзя объединить без потери информации.

Значит, число состояний на каждом ярусе уже минимально возможное, и решетка минимальна.

---

## 15. Коротко для запоминания

Главная идея:

> Минимальная решетка линейного кода строится по активным строкам порождающей матрицы.

Для каждой строки находим:

- \(b_i\) — первое ненулевое место;
- \(e_i\) — последнее ненулевое место.

На ярусе \(j\) активны строки, для которых

\[
b_i \le j < e_i.
\]

Если активны \(r\) независимых строк, число состояний на ярусе равно

\[
2^r.
\]

В рассмотренном примере профиль:

\[
1,\ 8,\ 8,\ 8,\ 4,\ 2,\ 1.
\]

---

## 16. Самый короткий итог

Треллис — граф, описывающий все кодовые слова линейного кода.

Минимальная решетка — треллис без лишних состояний.

Алгоритм построения:

1. Взять порождающую матрицу \(G\).
2. Для каждой строки найти спэн \([b_i,e_i]\).
3. Определить активные строки на каждом ярусе.
4. По активным строкам вычислить состояния.
5. Получить профиль решетки.
6. Если матрица в минимальной спэновой форме, решетка минимальна.

Для примера из лекции:

\[
\boxed{1,\ 8,\ 8,\ 8,\ 4,\ 2,\ 1}.
\]
