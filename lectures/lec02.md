# Лекция 2. Коды Хэмминга, дуальные коды и простейшие примеры

## 1. Напоминание: линейный блочный код

Рассматриваем двоичные линейные блочные коды длины `n` и размерности `k`.

- Кодовое слово — вектор длины `n` над полем `F₂ = {0,1}`.
- Информационное слово — вектор длины `k`.
- Обозначение кода: `(n, k)`-код.
- Скорость кода:

R = k/n

### Основные объекты

- Вес Хэмминга `w(x)` — число единиц в слове `x`.
- Расстояние Хэмминга `d(x,y)` — число позиций, в которых слова `x` и `y` различаются.
- Минимальное расстояние кода:

d_min = min d(x,y) по всем различным кодовым словам x≠y

Для линейного кода:

d_min = min w(x) по всем ненулевым x в коде

### Исправление ошибок

Если минимальное расстояние кода равно `d_min`, то код может:

- исправлять

t = floor((d_min−1)/2)

ошибок;
- обнаруживать до `d_min−1` ошибок.

---

## 2. Коды Хэмминга: идея и параметры

Коды Хэмминга — важный класс линейных блочных кодов, которые:

- имеют небольшое избыточное число проверочных бит,
- при этом умеют исправлять одну ошибку в блоке.

### Параметры стандартного двоичного кода Хэмминга

Для натурального `m ≥ 2` строится код со следующими параметрами:

- длина кодового слова:

n = 2^m − 1

- число информационных символов:

k = n − m = 2^m − 1 − m

- число проверочных символов (бит чётности): `m`;
- минимальное расстояние:

d_min = 3

Такой код исправляет одну ошибку в каждом блоке длины `n`.

---

## 3. Проверочная матрица кода Хэмминга

Код Хэмминга удобно определять через проверочную матрицу `H`.

### Как строится H

- Размер матрицы: `m × n`, где `n = 2^m − 1`.
- Столбцы матрицы — все ненулевые двоичные векторы длины `m`.
- Каждый столбец соответствует определённой позиции кодового слова.

Запись условия принадлежности кодовому пространству:

H cᵀ = 0

где `c` — кодовое слово длины `n`.

### Синдром ошибки

Если переданное кодовое слово было искажено ошибкой `e`, на приёмнике получаем `r = c + e`.

- Синдром:

s = H rᵀ = H (c+e)ᵀ = H cᵀ + H eᵀ = 0 + H eᵀ = H eᵀ

- Если ровно один бит испорчен, то вектор ошибки `e` имеет вес 1, и его синдром совпадает с соответствующим столбцом матрицы `H`.
- Значит, по синдрому можно однозначно определить одну ошибочную позицию и исправить её.

## 4. Линейные коды и дуальность

Пусть `C` — линейный код длины `n` и размерности `k` над `F₂`.

### Определение дуального кода

Дуальный код `C^⊥` определяется как множество всех векторов, ортогональных ко всем кодовым словам `C`:

C^⊥ = { x ∈ F₂^n : x cᵀ = 0 для всех c ∈ C }

Свойства:

- `C^⊥` — тоже линейный код длины `n`.
- Размерности связаны:

dim C + dim C^⊥ = n

то есть, если `C` — `(n,k)`-код, то `C^⊥` — `(n, n−k)`-код.

### Матрицы G и H

- Порождающая матрица `G` кода `C` имеет размер `k × n`.
- Проверочная матрица `H` кода `C` имеет размер `(n−k) × n`.
- Для линейного кода выполняется:

G Hᵀ = 0

где `строки G` образуют базис `C`, а `строки H` — базис дуального кода `C^⊥`.

Отсюда:

- `H` является проверочной матрицей для `C`,
- и одновременно порождающей матрицей для `C^⊥`.

## 5. Дуальный код Хэмминга и симплекс-код

Рассмотрим стандартный двоичный код Хэмминга параметров `(2^m−1, 2^m−1−m)`.

### Дуальный код

- Проверочная матрица `H` кода Хэмминга имеет размер `m × (2^m−1)` и столбцы — все ненулевые векторы длины `m`.
- Дуальный код `C^⊥` имеет параметры:

длина: n = 2^m − 1  
размерность: m  

то есть `(2^m−1, m)`-код.

Порождающая матрица дуального кода — это та же самая матрица `H`.

### Вес и структура дуального кода

Пусть `a` — ненулевой вектор длины `m`. Ему соответствует кодовое слово дуального кода:

v = a H

- `j`-я координата слова `v` равна скалярному произведению `a ⋅ h_j`, где `h_j` — `j`-й столбец `H`.
- Отображение `h ↦ a ⋅ h` — ненулевая линейная функция на `F₂^m`.
- Такая функция принимает значение `1` ровно на половине всех векторов длины `m`.

Всего двоичных векторов длины `m` — `2^m`. Из них:

- один — нулевой,  
- остальные `2^m−1` как раз являются столбцами `H`.

Из свойств линейной функции:

- среди всех `2^m` векторов значение `1` встречается ровно `2^{m−1}` раз,
- при этом нулевой вектор даёт значение `0`.

Значит, среди `2^m−1` ненулевых векторов значение `1` встречается всё равно `2^{m−1}` раз.

Отсюда:

- у любого ненулевого слова `v = aH` вес

w(v) = 2^{m−1}

- все ненулевые кодовые слова дуального кода имеют один и тот же вес.

Такой код называется **симплекс-кодом**.

### Параметры симплекс-кода

Для данного `m`:

- длина: n = 2^m − 1  
- размерность: m  
- минимальное расстояние:

d_min = 2^{m−1}

## 6. Код с проверкой на чётность

Код с проверкой на чётность (even-parity code) — один из самых простых линейных кодов.

### Определение

Чаще всего его определяют так:

C = { x ∈ F₂^n : x₁ ⊕ x₂ ⊕ … ⊕ x_n = 0 }

То есть сумма всех координат по mod 2 равна нулю, число единиц в слове — чётное.

### Параметры

- длина: n  
- размерность: k = n − 1  
- минимальное расстояние:

d_min = 2

потому что есть кодовые слова веса 2 (две единицы на разных позициях).

### Проверочная матрица

Проверочная матрица имеет вид:

H = (1 1 … 1)

то есть одна строка, состоящая из единиц.

---

## 7. Дуальный код кода с проверкой на чётность: код повторения

Дуальный код кода с проверкой на чётность получается из матрицы `H`.

### Структура дуального кода

- Порождающая матрица дуального кода совпадает с `H`.
- Значит, дуальный код состоит из всех линейных комбинаций строки `11…1`.

Итого кодовые слова дуального кода:

- 00…0  
- 11…1

Это называется **кодом повторения** (repetition code).

### Параметры кода повторения

- длина: n  
- размерность: k = 1  
- минимальное расстояние:

d_min = n

так как расстояние между `00…0` и `11…1` равно `n`.

### Исправление ошибок

По общей формуле:

t = floor((d_min−1)/2) = floor((n−1)/2)

то есть код повторения исправляет любую конфигурацию ошибок, если число ошибочных бит строго меньше половины длины слова.

На практике такой код можно декодировать по правилу **большинства**:
- если в принятом слове больше нулей — решаем, что было послано `00…0`,
- если больше единиц — решаем, что было послано `11…1`.
