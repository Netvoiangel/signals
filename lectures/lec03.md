# Лекция 3. Синдромное декодирование, вырожденные коды и граница Хэмминга. Код Голея

## 1. Матрицы G и H: ещё раз про линейные коды

Рассматриваем двоичный линейный блочный код длины `n` и размерности `k`.

- Порождающая матрица `G` имеет размер `k × n`.
- Проверочная матрица `H` имеет размер `(n−k) × n`.
- Строки `G` образуют базис кода `C`.
- Строки `H` образуют базис дуального кода `C^⊥`.

Условие принадлежности векторa `c` коду:

H cᵀ = 0.

Связь между `G` и `H`:

G Hᵀ = 0.

То есть каждая строка `G` ортогональна каждой строке `H` (по mod 2).

### Получение H по G

Пусть дана порождающая матрица `G`. Тогда:

- пространство всех векторов длины `n` — это `F₂^n`,
- код `C` — подпространство размерности `k`,
- дуальное подпространство `C^⊥` имеет размерность `n−k`.

Матрицу `H` можно получить как базис ортогонального дополнения:

- найти все векторы `h`, такие что `h` ортогонален всем строкам `G`,
- выбрать из них `n−k` линейно независимых — это строки `H`.

На практике часто приводят `G` к систематическому виду

G = ( I_k | P )

и тогда проверочная матрица может быть выбрана как

H = ( −Pᵀ | I_{n−k} ),

где `I_k` и `I_{n−k}` — единичные матрицы. Все операции — по mod 2, так что знак минус не отличим от плюса.

## 2. Синдром и синдромное декодирование

Пусть `C` — линейный код с проверочной матрицей `H`.

### Синдром

Для любого вектора `r ∈ F₂^n` определим синдром:

s(r) = H rᵀ.

Свойства:

- если `c ∈ C`, то `H cᵀ = 0`, значит синдром кодового слова равен нулю;
- синдром зависит только от класса смежности по коду:

если `r = c + e`, где `c ∈ C`, то

s(r) = H(c+e)ᵀ = H cᵀ + H eᵀ = 0 + H eᵀ = H eᵀ.

То есть синдром определяется только вектором ошибки `e`.

### Смысл синдрома

- синдром показывает, в какой “косет” вида `C + e` попал принятый вектор;
- каждый косет можно представить в виде `C + e₀`, где `e₀` — выбранный “стандартный представитель” (обычно берут наименьший по весу);
- если мы знаем синдром `s` и заранее выбрали вектор ошибки `e(s)` для каждого возможного синдрома, то можем:
  - восстановить оценку переданного кода как

    ĉ = r − e(s) = r + e(s)

    (так как всё по mod 2).

### Таблица синдромного декодирования

Так как синдром `s` — вектор длины `n−k`, всего возможных синдромов:

2^{n−k}.

Таблица синдромного декодирования:

- перечисляем все возможные синдромы `s`,
- для каждого синдрома выбираем один вектор ошибки `e(s)` (обычно с минимальным весом),
- храним соответствие:

синдром s ↔ “наиболее вероятная ошибка” e(s).

Алгоритм:

1. Принять вектор `r`.
2. Вычислить синдром `s = H rᵀ`.
3. Найти по таблице вектор `e(s)`.
4. Выдать оценку кода: `ĉ = r + e(s)`.

Если код исправляет до `t` ошибок, то выбор `e(s)` по весу до `t` гарантирует корректное декодирование.

## 3. Вырожденные коды

Напоминание: минимальное расстояние кода:

d_min = min w(c) по всем ненулевым c ∈ C.

### Невырожденный код

Код называют **невырожденным**, если:

- все столбцы проверочной матрицы `H` ненулевые,
- нет ненулевых кодовых слов слишком малого веса, “скрытых” в структуре кода.

Интуитивно: каждый столбец `H` соответствует своей ошибке в одной позиции; разные столбцы дают разные синдромы.

### Вырожденный код

Код называют **вырожденным**, если:

- существует ненулевое кодовое слово маленького веса (например, веса 1 или 2),
- или некоторые столбцы `H` совпадают или даже равны нулю (какие‑то ошибки неотличимы по синдрому от других или от отсутствия ошибки).

Последствия:

- минимальное расстояние может быть очень маленьким (например, 1),
- код плохо обнаруживает и тем более плохо исправляет ошибки,
- синдромное декодирование не даёт однозначного вывода, даже если предполагаем малый вес ошибки.

**Пример:** если в коде есть кодовое слово веса 1, то:

- одна и та же позиция может “испортиться” так, что результат всё ещё является корректным кодовым словом,
- при этом синдром не меняется, и по принятым данным невозможно понять, была ошибка или нет.

## 4. Граница Хэмминга (граница упаковки сфер)

Рассмотрим двоичный \((n,M,d)\)-код, который исправляет до `t` ошибок, то есть

d_min ≥ 2t + 1.

### Объём шара Хэмминга

Шар Хэмминга радиуса `t` вокруг вектора длины `n`:

все векторы, отличающиеся не более чем в `t` позициях.

Число векторов в таком шаре:

V₂(n,t) = ∑_{i=0}^t C(n,i).

### Неравенство Хэмминга

Шары радиуса `t` вокруг разных кодовых слов не пересекаются (иначе одно и то же слово могло бы быть ближе чем на `t` к двум разным кодовым словам, что противоречит `d_min ≥ 2t+1`).

Поэтому:

M · V₂(n,t) ≤ 2^n.

Это — **граница Хэмминга** (граница упаковки сфер).

Для **линейного** кода размерности `k`:

M = 2^k,

и граница принимает вид:

2^k · ∑_{i=0}^t C(n,i) ≤ 2^n.

### Совершенные коды

Код называется **совершенным**, если выполняется равенство:

M · V₂(n,t) = 2^n.

То есть шары радиуса `t` вокруг кодовых слов:

- попарно не пересекаются,
- полностью заполняют всё пространство `F₂^n` без “дыр”.

В этом случае говорят, что код **достигает границы Хэмминга**.

## 5. Код Голея (23,12,7)

Одним из важнейших примеров совершенного кода является двоичный код Голея.

### Параметры кода Голея

Двоичный код Голея имеет параметры:

- длина: n = 23,
- размерность: k = 12,
- число кодовых слов: M = 2^{12} = 4096,
- минимальное расстояние: d_min = 7.

Обычно его записывают как \((23,12,7)\)-код Голея.

Исправляемое число ошибок:

t = floor((d_min−1)/2) = floor((7−1)/2) = 3.

То есть код исправляет до трёх ошибок в каждом слове длины 23.

---

## 6. Код Голея и граница Хэмминга

Проверим, что код Голея достигает границы Хэмминга.

Радиус корректируемых ошибок: t = 3.

Объём шара Хэмминга радиуса 3 в `F₂^{23}`:

V₂(23,3) = C(23,0) + C(23,1) + C(23,2) + C(23,3).

Посчитаем:

- C(23,0) = 1,
- C(23,1) = 23,
- C(23,2) = 253,
- C(23,3) = 1771.

Сумма:

V₂(23,3) = 1 + 23 + 253 + 1771 = 2048 = 2^{11}.

Подставим в границу Хэмминга:

2^k · V₂(23,3) ≤ 2^{23}.

Для кода Голея `k = 12`, значит левая часть:

2^{12} · 2^{11} = 2^{23}.

Получаем точное равенство:

2^{12} · V₂(23,3) = 2^{23}.

Следствия:

- шары радиуса 3 вокруг всех кодовых слов кода Голея разбивают `F₂^{23}` на непересекающиеся области,
- ни один вектор не остаётся “без шара” и не попадает в пересечение двух шаров.

Поэтому:

- код Голея \((23,12,7)\) **совершенный**,
- он **достигает границы Хэмминга**.
